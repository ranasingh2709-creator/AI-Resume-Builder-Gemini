# AI Resume Builder

An AI-powered Resume Builder built using Python, Streamlit, Gemini API, and ReportLab.

## Features

- Generate professional resumes using AI
- Internship-focused resume summaries
- PDF download support
- Clean Streamlit interface
- Gemini AI integration

## Tech Stack

- Python
- Streamlit
- Gemini API
- ReportLab

## Installation

```bash
pip install -r requirements.txt
```

## Run Project

```bash
streamlit run app.py
```
