🚀 AI Resume Builder

An AI-powered Resume Builder developed using Python, Streamlit, Gemini API, and ReportLab. This application helps students and job seekers generate ATS-friendly, professional resumes instantly and export them as PDF documents.

📌 Features

- AI-powered resume generation using Gemini AI
- ATS Resume Score Analysis
- Professional resume formatting
- PDF Resume Export
- Multiple Resume Styles
- Internship-ready resume creation
- User-friendly Streamlit interface
- Cloud deployment using Streamlit Cloud

🛠 Tech Stack

- Python
- Streamlit
- Gemini API
- ReportLab
- HTML/CSS

📂 Project Workflow

1. Enter personal and academic details.
2. Add technical skills, projects, certifications, and achievements.
3. Generate a professional ATS-friendly resume using Gemini AI.
4. Analyze resume quality through ATS Score.
5. Download the generated resume as a PDF.
